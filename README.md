One word, the first that comes to mind — and the most interesting word wins.
This entry is **defenestration**: the act of throwing someone out of a window.
Surprising, vivid, and witty, with the Defenestrations of Prague behind it —
one image lands instantly, and it feels chosen rather than generic.

## Run

